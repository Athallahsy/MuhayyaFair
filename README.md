# 🎉 Muhayya Fair 2025 — Event Landing Page

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Bootstrap](https://img.shields.io/badge/Bootstrap-5-7952B3?style=for-the-badge&logo=bootstrap&logoColor=white)

A responsive event landing page built for **Muhayya Fair 2025** — an annual competition festival held by SD Muhammadiyah Hajjah Nuriyah, Banjarbaru. This project was a real client project made to help the school promote the event and manage competition registrations online.

## ✨ Features

- 🎨 Attractive hero section with scroll animations
- 📋 Competition categories for TK & SD levels
- 📅 Event schedule & location info
- 📄 Direct links to competition guidelines (Google Drive)
- 📝 Online registration links (Google Forms)
- 💬 WhatsApp group invitation link
- 📱 Social media links (Instagram, YouTube, TikTok)
- 📲 Fully responsive on mobile & desktop

## 🎯 About the Event

**Muhayya Fair** is an annual festival held by SD Muhammadiyah Hajjah Nuriyah Banjarbaru as a platform for students to showcase their talents and achievements. The 2025 edition featured competitions for both TK and SD levels, including Tahfidz, Mewarnai, Fashion Show, Drumband, Vocal Grup, and Cerdas Cermat.

📅 **Date:** Wednesday–Thursday, 26–27 November 2025  
📍 **Location:** SD Muhammadiyah Hajjah Nuriyah, Banjarbaru
